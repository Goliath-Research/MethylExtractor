MethylExtractor

High-performance DNA methylation analysis from bisulfite sequencing data

Overview

MethylExtractor is a high-performance tool for extracting DNA methylation data from bisulfite sequencing BAM files. It analyzes methylation patterns at CpG, CHG, and CHH sites, providing comprehensive methylation analysis with advanced features for quality control and overlapping read handling.

The tool processes aligned bisulfite sequencing data to identify methylated and unmethylated cytosines across different genomic contexts, producing detailed methylation statistics and coverage information.

Key Benefits:
  • ⚡ High-performance multi-threaded processing
  • 🔬 Advanced overlapping read pair handling
  • 📊 Comprehensive quality filtering and control
  • 💾 Flexible output formats (HDF5, text, or both)
  • 🎯 Deterministic results regardless of thread count

Installation

Prerequisites

MethylExtractor requires the following system dependencies:

  • HTSlib (for BAM/SAM file handling)
  • HDF5 (for binary output format)
  • Zlib, Bzip2, LZMA, and other compression libraries
  • GCC compiler with OpenMP support

Building from Source

git clone <repository-url> cd MethylExtractor make

The Makefile will automatically download and install required system dependencies, then compile the program optimized for your architecture.

Verification

After successful compilation, verify the installation:

./build/dynamic/arm64/MethylExtractor --help
Note: The binary will be located in build/dynamic/arm64/ (or build/dynamic/x64/ on x86 systems).

Usage

Basic Syntax

MethylExtractor [options] <input.bam> <output_directory> [reference.fa]

Command-Line Options

Option Description Default
-h, --help Show help message and exit N/A
-t, --threads INT Number of threads for processing 16
-q, --min-mapq INT Minimum mapping quality (MAPQ) 30
-p, --min-phred INT Minimum base quality (Phred score) 20
-c, --min-cov INT Minimum coverage threshold 4
-C, --cap-cov INT Cap coverage to this value (0 = disabled) 0
-G, --CHG Include CHG methylation contexts Disabled
-H, --CHH Include CHH methylation contexts Disabled
-m, --chrom-mapping FILE Chromosome mapping configuration file chrom_mapping.json
-z, --compression INT HDF5 compression level (0-9) 6
-k, --chunk-size INT HDF5 chunk size for I/O optimization 1,000,000
-f, --output-format STR Output format: hdf5, txt, or both hdf5
-s, --split Split output by methylation context Disabled
-o, --output-dir DIR Output directory (overrides positional argument) N/A

Chromosome Mapping File

The chromosome mapping file (chrom_mapping.json) defines which chromosomes to process and their corresponding reference sequences:

{ "reference": "/path/to/genome.fa", "chromosomes": [ { "name": "chr1", "fasta": "chr1", "bam": "chr1", "extract": true }, { "name": "chr2", "fasta": "chr2", "bam": "chr2", "extract": true } ] }
Tip: If no chromosome mapping file is provided, MethylExtractor will look for chrom_mapping.json in the same directory as the input BAM file.

Quality Control Features

MethylExtractor implements rigorous quality control:
  • Reads with MAPQ < 30 are filtered out
  • Bases with Phred quality < 20 are excluded
  • PCR duplicates and secondary alignments are removed
  • Overlapping read pairs are properly handled to prevent double-counting
  • Bisulfite conversion patterns are validated

Output Formats

HDF5 Format (Default)

The HDF5 output provides efficient storage and fast random access to methylation data:

Dataset: methylation_data ├── pos (uint32) - Genomic position (1-based) ├── mC (uint16) - Methylated cytosine count ├── uC (uint16) - Unmethylated cytosine count └── tnc (uint8) - Trinucleotide context and strand information

Text Format

Human-readable tab-separated format:

# Format: position strand methylated_count unmethylated_count context trinucleotide 161 + 11 9 CG CGT 310 - 8 12 CG CGA ...

Output Files

Option Output Files Description
-f hdf5 chr1.h5, chr2.h5, ... HDF5 files per chromosome
-f txt chr1.txt, chr2.txt, ... Text files per chromosome
-f both Both HDF5 and text files Combined output formats
-s --split chr1.CG.h5, chr1.CHG.h5, ... Separate files per context

Statistics Output

Each output includes a JSON statistics file with genome-wide methylation metrics:

{ "num_positions": 1345382, "total_methylated": 5084976, "total_unmethylated": 18665653, "avg_methylation_level": 0.214, "avg_coverage": 17.65 }

Examples

Basic Usage

# Process a single BAM file with default settings ./MethylExtractor input.bam output_dir reference.fa

High-Quality Analysis

# Strict quality filtering, multi-threading, all contexts ./MethylExtractor \ -t 16 \ -q 30 \ -p 20 \ -c 4 \ -G \ -H \ -f both \ -s \ input.bam \ output_dir \ reference.fa

Production Pipeline

# Optimized for production use ./MethylExtractor \ --threads 32 \ --min-mapq 30 \ --min-phred 20 \ --min-cov 5 \ --cap-cov 100 \ --CHG \ --CHH \ --output-format hdf5 \ --split \ --compression 9 \ sample.bam \ results/ \ genome.fa

Custom Chromosome Processing

# Use custom chromosome mapping ./MethylExtractor \ -m custom_chromosomes.json \ -t 8 \ input.bam \ output_dir

Quick Analysis

# Fast analysis with relaxed filtering ./MethylExtractor \ -t 4 \ -q 20 \ -p 15 \ -c 1 \ -f txt \ input.bam \ output_dir \ reference.fa

Performance & Best Practices

Threading Guidelines

Recommended thread counts:
  • Small datasets (< 10GB BAM): 4-8 threads
  • Medium datasets (10-50GB BAM): 8-16 threads
  • Large datasets (> 50GB BAM): 16-32 threads
  • Very large datasets: 32+ threads

Quality Filtering Recommendations

Parameter Conservative Standard Relaxed
--min-mapq 30 20 10
--min-phred 25 20 15
--min-cov 5 4 1

Memory Usage

MethylExtractor is designed for memory efficiency:

  • Streaming I/O prevents loading entire BAM files into memory
  • Per-chromosome processing with configurable chunk sizes
  • HDF5 chunked storage for optimal I/O performance
  • Memory usage scales with chromosome size, not genome size

Coverage Capping

Use coverage capping (-C) for:
  • PCR amplification bias correction
  • Normalization across samples with varying coverage
  • Reducing the impact of copy number variations

Troubleshooting

Common Issues

High memory usage
Reduce thread count or process fewer chromosomes simultaneously
Slow processing
Check I/O performance, consider SSD storage for large datasets
Empty output files
Check chromosome mapping file, verify BAM headers match reference
Low methylation levels
Verify bisulfite conversion efficiency, check quality filtering parameters

Performance Optimization

  • Use SSD storage for both input BAM files and output directories
  • Adjust chunk size (-k) based on chromosome sizes
  • Use appropriate compression levels (-z) for I/O balance
  • Consider processing large chromosomes separately for better memory management
